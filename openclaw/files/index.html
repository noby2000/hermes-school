Файлы

Все адреса и ключи заменены заглушками (<SERVER_IP> и т.п.).

  • SETUP-guest.md — инструкция для бота второго пользователя
  • SKILL-guest.md — навык для ботов второго пользователя
  • SKILL-owner.md — навык openclaw-delegate для своих ботов
  • oc-delegate — клиент владельца: отдать задачу OpenClaw
  • oc-delegate-guest — клиент второго пользователя (переименовать в oc-delegate)
  • oc-gate — сервер: forced command для ключа второго пользователя
  • oc-mail — клиент владельца: почта между ботами
  • oc-mail-guest — клиент второго пользователя (переименовать в oc-mail)
  • ocmail.py — сервер: почтовый ящик ботов
  • ocx.py — сервер: извлечение текста ответа из JSON
  • omniroute-mgmt.mjs — сервер: вызов локального API OmniRoute
  • omniroute-settings.json — тело PATCH /api/settings для OmniRoute
  • omniroute-test-models.mjs — сервер: тест моделей через OmniRoute
  • omniroute.env.example — шаблон ~/.omniroute/.env
  • omniroute.service — systemd user unit OmniRoute
  • openclaw-gateway.json — фрагмент конфига: шлюз и Tailscale
  • openclaw-gateway.service — systemd user unit шлюза OpenClaw
  • openclaw-models-agents.json — фрагмент конфига: модели, fallbacks, агенты, OmniRoute-провайдер
  • openclaw-no-omniroute.json — фрагмент конфига: без OmniRoute / откат
  • openclaw.env.example — шаблон ~/.openclaw/.env
