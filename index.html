☤ Школа Hermes

Пошаговый план: как научиться работать с Hermes Agent — открытым AI-агентом от Nous Research. Он умеет работать в терминале, пользоваться инструментами, создавать себе «навыки», помнить тебя между сессиями и отвечать в Telegram.

Цель

С помощью Hermes построить своё приложение для России — сервис для нутрициологов и фитнес-тренеров (клиенты, планы питания и тренировок, прогресс). Домен проекта уже есть: eatandfit.online. Hermes будет твоим напарником-разработчиком.

Дорожная карта

  1. Шаг 1. Подготовка с нуля — ← мы здесь
  2. Шаг 2. Первый запуск Hermes: разговор, модели, slash-команды
  3. Шаг 3. Идея и спецификация (OpenSpec + Hermes)
    Сначала спецификация — потом код. В папке проекта: 
    mkdir ~/eatandfit && cd ~/eatandfit && git init
openspec init --tools hermes
    init создаёт папку openspec/ (спецификации и изменения) и навыки Hermes в .hermes/skills/. Hermes по умолчанию читает навыки только из ~/.hermes/skills/, поэтому добавь папку проекта в ~/.hermes/config.yaml (init напомнит): 
    skills:
  external_dirs:
    - ~/eatandfit/.hermes/skills
    Цикл работы (в чате hermes):
    1. explore — обсудить идею без кода: кто пользователи (нутрициолог, тренер, клиент), что им нужно;
    2. propose — агент создаёт изменение в openspec/changes/<имя>/: предложение, спецификации, дизайн и список задач. Ты читаешь и правишь;
    3. apply — агент выполняет задачи и пишет код (в Hermes: /openspec-apply-change);
    4. archive — изменение готово, спецификации переносятся в основные openspec/specs/.
    Канонические имена в OpenSpec — /opsx:explore, /opsx:propose, /opsx:apply, /opsx:archive; в Hermes это навыки вида /openspec-… — точные имена напечатает openspec init. Не проверено: точные имена навыков, кроме openspec-apply-change.

    Первое изменение для eatandfit — например:

    /openspec-propose add-client-profile-and-meal-plan
Нутрициолог создаёт карточку клиента (имя, возраст, рост, вес, цель,
аллергии) и составляет ему план питания на неделю (приёмы пищи, калории,
БЖУ). Клиент видит свой план. Персональные данные — по 152-ФЗ, хранить в РФ.
    Потом проверь openspec list и файлы в openspec/changes/, поправь спецификацию — и только после этого apply. Не проверено: работу OpenSpec именно с Hermes на практике.
  4. Шаг 4. Инструменты, навыки и память Hermes — учим агента своему проекту (AGENTS.md, skills)
  5. Шаг 5. MVP: первая рабочая версия приложения в репозитории на GitHub
  6. Шаг 6. Деплой на eatandfit.online
  7. Шаг 7. Особенности РФ: персональные данные по 152-ФЗ (хранение в России, согласие), доступные из РФ LLM и платёжные системы
  8. Шаг 8. Telegram-бот через hermes gateway и автоматизации (cron)

Шаги 2–8 будут расписаны позже.
