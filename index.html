Пошаговый план: как научиться работать с Hermes Agent — открытым AI-агентом от Nous Research. Он умеет работать в терминале, пользоваться инструментами, создавать себе «навыки», помнить тебя между сессиями и отвечать в Telegram.

Дорожная карта

  1. Шаг 1. Подготовка с нуля — ← мы здесь
  2. Шаг 2. Первый запуск и первый разговор (hermes, hermes model, slash-команды)
  3. Шаг 3. Инструменты и навыки (tools, toolsets, skills)
  4. Шаг 4. Память (MEMORY.md, USER.md, поиск по прошлым сессиям)
  5. Шаг 5. Мессенджер-шлюз (Telegram через hermes gateway)
  6. Шаг 6. Автоматизации по расписанию (cron)
  7. Шаг 7. Свой проект с Hermes

Шаги 2–7 будут расписаны позже.
